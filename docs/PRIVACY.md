# Privacy

V-Router is offline-first and collects no telemetry by default. It does not send projects, toolpaths, machine profiles, usage events or crash data to a server.

Daily rolling diagnostic and crash logs are written only to the platform's local application-data directory under `v-router`. Recovery snapshots and the SQLite tool/machine/material library are stored in the same local application-data area. Users may delete those files at any time while V-Router is closed.
